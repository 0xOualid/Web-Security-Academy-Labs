# Web Security Academy Labs

Welcome to my PortSwigger Web Security Academy labs repository!

This repository contains my personal notes, payloads, and automation scripts while solving labs on the PortSwigger Web Security Academy.

The goal of this repository is simple:

- Learn web security concepts through hands-on practice
- Understand how common web vulnerabilities work
- Keep track of my progress
- Save the payloads and scripts I use for each lab
- Improve my scripting and automation skills
- Build a consistent cybersecurity learning habit

> This repository is mainly for myself, so the notes are kept short and practical: just the key idea and the working payload for each lab.
